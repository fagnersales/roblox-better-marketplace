Translate API

Translation endpoint for the Roblox Better Marketplace search engine.

Endpoint

GET /api/translate?q={phrase}

Authentication

Pass your token via the Authorization header:

Authorization: Bearer YOUR_TOKEN

Parameters

ParamTypeDescription
qstringWord or phrase in any language to translate to English

Response

{
  "variants": ["fire sword", "flame sword", "fire blade"]
}

Returns up to 3 English translations or synonym variations.

Status Codes

200Success
400Missing q parameter
401Invalid or missing token
405Method not allowed
500Translation failed

Roblox Example

local HttpService = game:GetService("HttpService")
local url = "https://your-app.vercel.app/api/translate?q="
local query = HttpService:UrlEncode("espada de fogo")

local result = HttpService:GetAsync(
    url .. query,
    false,
    { ["Authorization"] = "Bearer YOUR_TOKEN" }
)

local data = HttpService:JSONDecode(result)
-- data.variants = {"fire sword", "flame sword", "fire blade"}

Caching

Responses are cached at the edge for 24 hours with a 1-hour stale-while-revalidate window. Identical queries will be served instantly from cache.
